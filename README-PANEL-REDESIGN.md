# بازطراحی پنل کاربری

داشبورد پنل کاربری با الهام از تصویر مرجع بازطراحی شده است:
- منوی کاربری در سمت راست
- نوار بالایی و عنوان صفحه
- کارت خوشامدگویی آبی و آمار واقعی ثبت‌نام‌ها
- پیام‌ها، برنامه کلاس‌ها و دسترسی سریع
- چیدمان واکنش‌گرا برای موبایل

## اجرا
1. این پروژه را استخراج کنید.
2. فایل `.env` معتبر پروژه قبلی خود را در پوشه `project` کپی کنید.
3. در پوشه `project` اجرا کنید:
   `npm install`
   `npm run dev`

## توجه
بخش‌هایی مثل آزمون‌ها، کیف پول و فاکتورها در پروژه فعلی API و صفحه عملیاتی ندارند؛ در منو به‌صورت غیرفعال و با برچسب «به‌زودی» نشان داده می‌شوند تا کاربر به مسیر خراب هدایت نشود.
