# به‌روزرسانی پنل کاربری

در این نسخه ظاهر پنل دانش‌آموزی بازطراحی شده است:
- سایدبار اختصاصی با وضعیت فعال منوها و اطلاعات حساب
- هدر پنل و داشبورد خوش‌آمدگویی
- کارت‌های آماری متصل به تعداد ثبت‌نام‌ها و جلسات
- نمایش جلسات امروز و جلسات پیش‌رو
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

ساختار احراز هویت، APIها، مسیرها و اتصال Supabase موجود حفظ شده‌اند.

## اجرا

1. وابستگی‌ها را نصب کنید: `npm install`
2. فایل `.env.example` را به `.env` تغییر نام دهید و مقادیر پروژه Supabase خود را وارد کنید.
3. اجرا: `npm run dev`
4. ساخت نسخه انتشار: `npm run build`

این بازطراحی بر اساس ساختار موجود پروژه و با الهام از یک پنل آموزشی مدرن انجام شده است؛ برای تطبیق پیکسلی با پنل خصوصی ماز، اسکرین‌شات از صفحات پس از ورود لازم است.
