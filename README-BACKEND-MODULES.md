# راه‌اندازی ماژول‌های سمت سرور پنل

این نسخه ماژول‌های آزمون، ثبت‌نام آزمون، حضور و غیاب، کیف پول، فاکتورها، پیام‌ها، اطلاعیه‌ها و نظرسنجی‌ها را به Supabase متصل می‌کند.

## ۱) اعمال ساختار دیتابیس

1. وارد Supabase Dashboard پروژه شوید.
2. از منوی **SQL Editor** یک Query جدید بسازید.
3. محتوای فایل `supabase/migrations/20261110110000_enable_student_portal_modules.sql` را کامل اجرا کنید.
4. در بخش **Table Editor** بررسی کنید جدول‌های `exams`, `exam_registrations`, `attendance_records`, `wallet_accounts`, `wallet_transactions`, `invoices`, `messages`, `announcements`, `polls`, `poll_options`, `poll_votes` ساخته شده باشند.

این Migration را فقط یک‌بار اجرا کنید. آن را در همان پروژه Supabase اجرا کنید که جدول‌های قبلی `profiles`, `classes`, `enrollments` و توابع `is_admin()` را دارد.

## ۲) متغیرهای محیطی

فایل `.env.example` را به `.env` تغییر نام دهید و مقدارهای واقعی پروژه Supabase را قرار دهید:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY
```

کلید `service_role` را هرگز در فایل `.env` فرانت‌اند قرار ندهید.

## ۳) اجرا

```bash
npm install
npm run dev
```

## ۴) دسترسی مدیر

برای استفاده از ابزارهای مدیریتی داخل صفحات آزمون، حضور و غیاب، کیف پول، فاکتورها، پیام‌ها، اطلاعیه‌ها و نظرسنجی، حساب مدیر باید در جدول `profiles` دارای `role='admin'` باشد. نقش را فقط از حساب مالک پروژه و در محیط امن تنظیم کنید؛ هیچ کاربر عادی نباید بتواند نقش خودش را تغییر دهد.

مدیر می‌تواند آزمون بسازد، حضور و غیاب ثبت کند، درخواست شارژ کیف پول را تأیید/رد کند، فاکتور صادر و تسویه کند، به کاربر پیام بدهد، اطلاعیه منتشر و نظرسنجی بسازد.

## محدودیت پرداخت

در این نسخه درخواست شارژ کیف پول ثبت و توسط مدیر تأیید می‌شود و فاکتور توسط مدیر به وضعیت تسویه‌شده تغییر می‌کند. پرداخت آنلاین واقعی هنوز به اتصال درگاه پرداخت (مثلاً زرین‌پال/آیدی‌پی) و دریافت Merchant ID و پیاده‌سازی callback سمت سرور نیاز دارد؛ بدون اطلاعات پذیرنده نمی‌توان پرداخت آنلاین واقعی را فعال یا شبیه‌سازی امن کرد.

## نکته امنیتی

دسترسی جدول‌ها با Row Level Security محدود شده است. کلید عمومی Supabase برای کلاینت استفاده می‌شود و مجوزها در دیتابیس اعمال می‌شوند. برای استقرار عمومی، دامنه، سیاست‌های احراز هویت، ایمیل تأیید، پشتیبان‌گیری و محدودیت نرخ درخواست‌ها را نیز در Supabase تنظیم کنید.

## پوشش فعلی ماژول‌ها و موارد نیازمند سرویس بیرونی

- آزمون‌ها: مدیر آزمون آنلاین/حضوری ایجاد و منتشر می‌کند؛ کاربر ثبت‌نام می‌کند و وضعیت/نمره ثبت‌شده را می‌بیند. موتور اجرای آزمون شامل بانک سؤال، پاسخ‌دهی زمان‌دار و تصحیح خودکار در این مرحله پیاده نشده است.
- آزمون حضوری: سوابق حضور و غیاب در دیتابیس ذخیره می‌شود و مدیر می‌تواند رکورد حضور ثبت کند.
- کیف پول: درخواست افزایش اعتبار، گردش تراکنش و تأیید/رد مدیر فعال است. افزایش اعتبار خودکار فقط پس از اتصال درگاه پرداخت معتبر باید انجام شود.
- فاکتورها: صدور فاکتور و ثبت تسویه توسط مدیر فعال است؛ صفحه پرداخت آنلاین مشتری هنوز به درگاه متصل نیست.
- پیام‌ها: ارسال به پشتیبانی، پاسخ مدیر و نشان‌گذاری پیام دریافتی به‌عنوان خوانده‌شده فعال است.
- اطلاعیه‌ها و نظرسنجی‌ها: انتشار توسط مدیر و مشاهده/رأی توسط کاربر فعال است.
